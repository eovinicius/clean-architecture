# Inbox

Caixa de entrada do vault: achados de sessões de agentes, dúvidas de negócio sem resposta, planos de implementação e investigações.

- Nome: `AAAA-MM-DD-assunto.md` (ex.: `2026-10-17-duvida-sla-feriados.md`).
- Frontmatter mínimo: `title` e `tags`.
- Triagem periódica: vira spec, ADR, runbook, entrada no glossário — ou é apagado.
